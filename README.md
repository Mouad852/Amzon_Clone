# Amazon UI Clone — frontend practice project

Ce projet est une réplique simplifiée de certaines interfaces d’Amazon,
développée à des fins d'apprentissage et de pratique front-end. Il n’est ni un
produit Amazon officiel ni affilié à Amazon.

---

## ✨ Fonctionnalités

- Page d'accueil similaire à Amazon
- Liste de produits
- Panier d'achat
- Design responsive 

---

## 🧰 Technologies utilisées

- HTML
- CSS
- JavaScript

## Lancer localement

Le projet est composé de pages HTML, CSS et JavaScript statiques. Clonez ce
dépôt et ouvrez `amazon.html` dans un navigateur moderne.

```bash
git clone https://github.com/Mouad852/Amzon_Clone.git
cd Amzon_Clone
```

> Le nom du dépôt conserve une faute historique. Un renommage futur vers
> `amazon-ui-clone` rendrait son objectif plus clair, mais aucun renommage n’est
> effectué par cette documentation.
